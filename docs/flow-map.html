Each flow is split into steps. A step is code when a script runs it, agent when a model does it, and human when the owner decides. A flow is deterministic when every step is code, agent-taken when every step is the agent's, and mixed otherwise. Human decisions are gates and do not count.

"Today" counts a deterministic step as code only when it names a script, hook, or workflow file in this repository (the path is checked when the page is built). Whether a project has installed that script or hook is not checked, and a step with no file is a rule that asks an agent to do it by hand. "After conversion" assumes every deterministic step is scripted. Which steps are deterministic, judgment, or human is a classification kept in docs/flow-map.json; change it there and run node scripts/build-flow-map.js.
