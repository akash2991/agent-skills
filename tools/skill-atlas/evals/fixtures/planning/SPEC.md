# Approved design: local task export
Plan only; no implementation or external tracker calls.
An existing dependency-free Node CLI has cli.cjs (argument dispatch), store.cjs (readTasks returns {id,title,done}[]), and format.cjs (human-readable output). These paths are design context, not shipped code. Add `tasks export --format json|csv --output PATH` using only Node built-ins.
JSON preserves all three fields; CSV has a header, quotes commas/newlines/quotes correctly, and round-trips Unicode. Unknown formats fail before writing. Never overwrite an existing file. A failed write must not leave a partial target. Empty task lists work. Existing list behavior stays unchanged.
Two engineers, one week, total capacity 8 points. Use 1/2/3-point tasks. First milestone must deliver a usable JSON export. CSV may be deferred explicitly if capacity requires it. Cloud sync and a GUI are out of scope. Shared command/serializer contracts need a single owner before parallel implementation. No new runtime dependencies.
Deliver plan.md and plan.json. JSON shape: {"tasks":[{"id":"T1","paths":["cli.cjs"],"dependsOn":[],"points":1,"acceptance":["observable condition"],"verification":"proposed command"}],"milestones":[{"id":"M1","tasks":["T1"],"outcome":"usable result"}],"sprint":{"capacity":8,"tasks":["T1"]},"deferred":["reasoned deferral"]}.
Tasks with no dependency path between them are considered concurrent: give them disjoint file ownership or serialize. Proposed commands need not execute because this is a design-only fixture; label them as proposed. Explain tradeoffs, risks, user approval gate and rollback in plan.md.
