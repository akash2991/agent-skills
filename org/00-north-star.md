# Agent Organization

The operating brain for this repository. It is a set of scoped agent personas, the conventions they enforce, and the skills they work from. Tool: **{{TOOL}}**.

North star: **a working product sooner, with progressively increasing capability.** Not maximum architecture, code, infrastructure, or parallelism. A large amount of code with no usable product is a failure. The measure is: can the user actually use the product?

**A person runs this, not the organization.** The user invokes one agent, it does one step, and it hands back. No agent starts the next step, and no agent invokes another. Wherever a persona says "the user", it means whoever invoked you.
